# Delsys Test API
### Scope of Library 
	- [] Delsys API Pairing / Auto-Pairing + Connection
	- [] Delsys API Data Streaming
	- [] Connection to MES server / data fetching
	- [] Lab equipment standard control
    - [] Standardized data logging forma


### Lab Equipment Connection
Each piece of supported equipment is a child class fo the a piece of lab equipment that implements the basic functions pertaining to connection, disconnection and destruction. Under that you will find more specific commands in reguards to what each of the devices do / measure in the lab.

#### Compatible for devices:
	- Keithley DMM7510
